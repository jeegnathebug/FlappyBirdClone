# Flappy Bird Clone

Game created by following this [Youtube](https://www.youtube.com/watch?v=XtQMytORBmM) tutorial.

## Features

- Day/night cycle
- Highscore tracking
- Sound effects
- Keyboard and gamepad controls

## Controls

- <kbd>Space</kbd> or <kbd>A</kbd> to flap
- <kbd>Esc</kbd> or <kbd>Start</kbd> to pause

## Built With
- Unity
- C#

## Goal
Learn Unity basics and 2D game mechanics.
